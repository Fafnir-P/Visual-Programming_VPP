6. DEFECTS / OBSERVATIONS
   a) Missing flags give a confusing message. Running only --customer bob on the 23-card program: exit 1, "first must be a number." (internal port name, no hint which flag). Flags are not required in argparse; an absent Enter Number value reaches Calculate as None.
   b) Output for the second graph is typed loosely: change_pct prints 20.0 (a float, not text); labels decide the keys. Fine, but not formatted unless a Format card is used.
   c) The order list must be topological; the app only reports it as a gap ("runs before or without its source"). Not a defect, but a user dragging cards must get the run order right.
   d) The model path still sends the whole graph, not just the gap cards (known, in dev2 notes).
   e) Nothing wrong found in the 11-card output; C1-C4 pass in all runs.
   f) git status shows many modified project files (README, app.js, bedrock.js, ...) - these were not changed by me (I only created files under final_check\card_way2\ and the two measure2_card files).
