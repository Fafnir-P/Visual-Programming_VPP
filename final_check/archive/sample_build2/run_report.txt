WHAT THE NEW PROMPT STILL LACKED (what I had to guess)
 L1. Where card_templates comes from. The prompt says "module card_templates.runtime; do not copy it" and "run with python main.py",
     but a generated main.py in its own folder cannot import it. I ran with PYTHONPATH set. Prompt should say: put the project root
     on sys.path, or tell the model to add sys.path code, or say how the user starts it.
 L2. Value for Enter Text. Rule says read "--<config name>" with "the card's config default". Enter Text config has no default for the
     value (only name/label/required/...), and "config name" could mean the key "name" ("text") or the card's setting names.
     Read literally with no default it is a GAP, which would stop every Enter card. I chose --text with default None. Say clearly:
     flag name = config.name; default = None unless a default is given; None is allowed when required=false.
 L3. "Prints the final result": which card's output? I printed the banner view as JSON. Not defined.
 L4. How to handle CardError (traceback vs readable message vs exit code). I did nothing (prompt forbids inventing handling); output is a traceback.
 L5. Whether cards.py should include imports for names in runtimeNames (I put them at the top of cards.py). The prompt says to put them
     at the start, not which file.
 L6. Which file layout (cards.py + main.py is my choice; the prompt does not name files except main.py).
