2. DETERMINISTIC main.py
   prototype/compile.js: compileMainPy(graph) -> {ok, mainPy, gaps}. Writes sys.path block, argparse flag per unlinked input card (flag = its name setting), calls in run order with linked inputs taken from source outputs and all settings as keywords, JSON result, one except for CardError/ValueError/ArithmeticError (one line to stderr, exit 1). Result = terminal data cards (no outgoing data link): one -> its outputs (Build Summary Record -> its record); several -> object keyed by title.
   Gaps (ok:false, mainPy ''): duplicate or invalid flag names (names both cards), cards using ctx/store/files/network, control-port cards (triggers, routes, loops), input cards not in the CLI list, unlinked required inputs, several links into one input, link from a later card, Start linked to a data input, required setting with no value, any-typed terminal result, nothing to run.
   prototype/bedrock.js: serializeGraph() is now the full internal graph (uses nodeSettings); buildDeterministicFiles() -> cards.py + main.py with zero model tokens.
   prototype/app.js: runGeneration() builds files with the app when ok and records the meter (input 0, output 0, accounting estimate, note 'assembled by the app'); describeRequestSize() says "The model is not needed: 0 model tokens (estimate)" or lists the gaps and the estimate.
