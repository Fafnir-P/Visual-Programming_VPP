What the prompt lacked / defects found in the request:
1. Card settings cannot be set. serializeGraph sends only defaults; the app has no settings UI. Change Text Case default is 'upper' (need title), Calculate default is 'add' (need multiply). The prompt says pass defaults, so a literal reply is wrong. Repair had to override case='title' and operation='multiply' with no source in the graph.
2. Flag names come from the setting 'name'. Both Enter Number cards default to 'number', and Enter Text to 'text'. A literal main.py has duplicate --number (argparse crash) and --text, not --customer/--qty/--price. Repair renamed the flags using the spec, not the graph.
3. RESULT rule prints only the last card's outputs, so the spec JSON is not reachable; the prompt has no way to say which fields to print.
4. App Start 'event' -> Enter Text '_start' link was in the graph but implicit ports are filtered out of node inputs, and the edge is sent; harmless but the prompt says the event is not a call.
5. Prompt says validation is not allowed beyond cards; empty-name and number errors worked because cards raise CardError.
